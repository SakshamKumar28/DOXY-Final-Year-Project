# DOXY - Telemedicine Platform 
DOXY is a web-based telemedicine platform developed using Next.js and TypeScript to make healthcare more accessible and convenient. It enables patients to connect with healthcare professionals, book appointments, and attend online consultations through real-time video calling powered by WebRTC. The platform incorporates secure authentication and real-time communication to provide a seamless healthcare experience. Its primary objective is to reduce geographical barriers, travel expenses, and waiting time, particularly for people in rural and underserved communities.

## Features
- User-friendly interface for patients and doctors.
- Secure authentication and authorization for both patients and doctors.
- Real-time video calling for online consultations.
- Appointment scheduling and management.
- Prescription management and history tracking.

## Technologies Used
- Next.js: A React framework for building server-side rendered applications.
- TypeScript: A statically typed superset of JavaScript for improved code quality and maintainability.
- WebRTC: A technology for real-time communication, enabling video calls directly in the browser.
- Tailwind CSS: A utility-first CSS framework for rapid UI development.

## Getting Started
To get started with DOXY, follow these steps:
1. Clone the repository:
   ```bash
   git clone <repository-url>
    ```
2. Navigate to the project directory:
   ```bash
   cd DOXY
   ```
3. Install dependencies:
   ```bash
   npm install
   ```  
4. Start the development server:
   ```bash
   npm run dev
   ```
